# Road Calibration UI

A dependency-free, responsive HTML prototype for road-plane camera calibration.

## Features

- Interactive four-point road-plane alignment
- Live pitch, yaw, and calibration-quality feedback
- Road width and reference-distance controls
- Undo, reset, zoom, and local save actions
- Responsive desktop, tablet, and mobile layouts
- No build step or external runtime dependencies

## Run locally

Open `index.html` directly, or start any static file server in this directory:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
